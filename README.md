# NEXUM
### Next-Gen Expansion Intelligence for UMKM

**NEXUM** merupakan aplikasi berbasis web yang dirancang untuk membantu pelaku Usaha Mikro, Kecil, dan Menengah (UMKM) dalam mengambil keputusan strategis terkait ekspansi bisnis melalui pendekatan *data-driven decision making*, dengan dukungan kecerdasan buatan generatif dan analisis data.

---

## Tentang NEXUM

Ekspansi bisnis merupakan salah satu strategi pengembangan usaha yang memerlukan pertimbangan matang, khususnya dalam pemilihan lokasi dan evaluasi kondisi keuangan.

NEXUM dikembangkan sebagai solusi digital yang membantu pelaku UMKM melakukan evaluasi bisnis melalui pengolahan data, visualisasi informasi, dan konsultasi berbasis kecerdasan buatan.

## Tujuan Pengembangan

1. Membantu pelaku UMKM mengevaluasi kelayakan lokasi untuk ekspansi bisnis.
2. Mengidentifikasi indikator risiko kegagalan usaha berdasarkan analisis laporan keuangan.
3. Menyediakan informasi bisnis melalui visualisasi *Business Intelligence*.
4. Membantu pelaku UMKM memperoleh konsultasi dan rekomendasi bisnis berbasis AI.

## Fitur Utama

### 1. Prediksi Kelayakan Lokasi Ekspansi
Membantu pelaku UMKM mengevaluasi calon lokasi ekspansi berdasarkan koordinat geografis dan indikator pendukung yang dimasukkan pengguna.

Fitur:
- Input koordinat latitude dan longitude dari Google Maps.
- Input data pendukung lokasi.
- Analisis dan perhitungan skor kelayakan lokasi.
- Penyajian hasil analisis dan kategori kelayakan.

### 2. Analisis Pola Kegagalan Usaha
Membantu pelaku UMKM mengidentifikasi indikator risiko kesulitan keuangan berdasarkan laporan keuangan usaha.

Fitur:
- Upload laporan keuangan berformat Excel (.xlsx).
- Validasi dan pengolahan data laporan keuangan.
- Perhitungan rasio keuangan.
- Identifikasi indikator risiko keuangan.
- Penyajian hasil analisis.

### 3. Dashboard Business Intelligence
Menyediakan visualisasi informasi bisnis untuk membantu pengguna memahami kondisi usaha.

Fitur:
- Ringkasan informasi usaha.
- Visualisasi pendapatan, beban, dan laba.
- Visualisasi indikator keuangan.
- Ringkasan hasil analisis lokasi.
- Riwayat hasil analisis.

### 4. Asisten Konsultasi Bisnis Berbasis AI
Menyediakan layanan konsultasi bisnis melalui integrasi Generative AI.

Fitur:
- Konsultasi bisnis melalui antarmuka percakapan.
- Penjelasan hasil analisis bisnis.
- Rekomendasi terkait pengembangan dan ekspansi usaha.

## Ruang Lingkup Pengembangan

Pengembangan NEXUM dilakukan dengan pendekatan *Minimum Viable Product* (MVP).

Batasan pengembangan awal:
- Aplikasi dikembangkan berbasis web responsif.
- Input koordinat lokasi dilakukan secara manual.
- Data pendukung analisis lokasi diinput oleh pengguna.
- Analisis lokasi menggunakan pendekatan penilaian multikriteria.
- Analisis keuangan menggunakan template laporan Excel standar NEXUM.
- Dashboard menggunakan data yang tersimpan dalam sistem.
- Asisten AI menggunakan layanan API LLM pihak ketiga.
- Sistem tidak menjamin keberhasilan ekspansi maupun memprediksi kegagalan usaha secara pasti.
